# Security policy

This is an early research reference repository. Do not deploy it to a production MES.

Do not publish secrets, operational records, personal data, SAP extracts, proprietary documents, or real factory schedules without written authorization.

If you discover a vulnerability or an accidentally published secret, do not disclose the secret in a public issue. Contact the repository maintainer privately using GitHub's private vulnerability reporting facility if enabled. Revoke/rotate affected credentials immediately and investigate repository history.
